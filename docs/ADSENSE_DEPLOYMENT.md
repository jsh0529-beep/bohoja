# AdSense 연결 체크리스트

## 현재 상태

- 보호자노트는 무료 서비스로 동작한다.
- 광고 컴포넌트는 공개 랜딩 페이지에만 배치되어 있다.
- 환경변수 두 개가 비어 있으면 광고 코드 자체를 렌더링하지 않는다.
- 환자 정보가 있는 로그인 화면과 돌봄방, 문서, 가족 기록, 마음쉼터에는 광고를 표시하지 않는다.

## 실제 광고를 켜는 순서

1. 보호자노트를 HTTPS 공개 주소에 배포하고 고유 도메인을 연결한다.
2. AdSense의 사이트 목록에 그 도메인을 새 사이트로 추가한다. 다른 서비스의 도메인에 발급된 광고 단위를 재사용하지 않는다.
3. 사이트 소유권 확인과 검토를 완료한다.
4. 반응형 디스플레이 광고 단위를 만들고 게시자 ID와 광고 슬롯 ID를 확인한다.
5. 배포 환경에 다음 값을 설정한 뒤 다시 빌드한다.

```text
NEXT_PUBLIC_ADSENSE_CLIENT=ca-pub-xxxxxxxxxxxxxxxx
NEXT_PUBLIC_ADSENSE_SLOT=xxxxxxxxxx
```

6. 공개 랜딩 페이지에서만 광고가 보이는지, 로그인 뒤 민감정보 화면에는 광고 요청이 전혀 없는지 점검한다.
7. 개인정보 처리방침에 광고 쿠키, 웹 비콘, 제3자 제공자, 맞춤 광고 설정 및 거부 방법을 실제 운영 내용에 맞게 게시한다.

## 운영 원칙

- 건강·의료정보를 광고 개인화나 타기팅에 사용하지 않는다.
- 광고를 버튼, 메뉴, 다운로드 링크처럼 보이게 꾸미지 않는다.
- 클릭을 유도하는 문구나 보상을 제공하지 않는다.
- 앱의 핵심 기능을 광고 시청과 연결하지 않는다.
- 계정에 사이트가 승인되기 전에는 환경변수를 설정하지 않는다.
