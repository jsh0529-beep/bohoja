# 공지·정책 CMS 운영

## 문서 유형

이용약관, 개인정보 처리방침, 가입 개인정보 동의, 민감정보 동의, 마케팅 안내, 제3자 제공, 국외 이전, 유료서비스/환불, 위탁 현황, 공지·업데이트·보안 공지를 구분한다. 처리방침 공개와 법적 근거가 동의인 처리를 혼동하지 않는다.

## 버전 수명주기

`DRAFT → IN_REVIEW → SCHEDULED → PUBLISHED → SUPERSEDED|WITHDRAWN`. 게시된 본문은 수정하지 않고 새 버전을 만든다. locale, 효력일, 게시일, 변경 요약, 재동의 필요 여부, 중요도, 작성/검토/게시자와 SHA-256을 기록한다.

## 게시 절차

1. 담당자가 실제 사업자·공급자 구성에 맞춰 초안을 작성한다.
2. 법무/개인정보 담당이 검토하고 미확정 placeholder를 검사한다.
3. 변경 비교, 대상 회원, 사전 고지일, 재동의 여부를 정한다.
4. 이중 승인 후 예약 게시하고 캐시를 무효화한다.
5. 앱/이메일 등 허용 채널로 통지하고 성공·실패를 기록한다.
6. 필요 시 다음 민감 기능 접근 전에 명시적 재동의를 받는다.

사용자 증적은 제시된 불변 버전, 본문 해시, 동의/확인 시각과 채널을 남긴다. 단순 오탈자 정정도 게시 버전을 바꾸되 재동의 필요 여부는 법무가 판단한다. 긴급 보안 공지는 공개 범위를 조절하며 공격 재현 정보와 개인정보를 노출하지 않는다.
