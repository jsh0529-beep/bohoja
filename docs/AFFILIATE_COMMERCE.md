# 입원 준비물 제휴 운영 원칙

## 목적

보호자노트의 모든 핵심 기능은 무료로 제공한다. 사용자가 입원 생활용품을 준비할 때 선택적으로 이용하는 쿠팡파트너스 링크를 운영비 보조 수단으로 사용한다.

## 필수 고지

제휴 링크보다 먼저, 모바일에서도 줄임 없이 다음 문구를 표시한다.

> 이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다.

링크에는 `rel="sponsored noopener noreferrer"`를 적용한다. 광고·제휴임을 숨기거나 일반 기능 버튼으로 오인하게 만들지 않는다.

## 추천 범위

- 실내화, 세면도구, 물티슈, 수면안대·귀마개, 보호자 방석, 충전 케이블, 정리 파우치 같은 비의료 생활용품만 다룬다.
- 약, 건강기능식품, 의료기기, 질환별 식품은 추천하지 않는다.
- 환자 질환, 병원명, 문서, 검색 기록, 가족 기록에 따른 개인화나 타기팅을 하지 않는다.
- 병원 제공품과 반입 규정, 환자 안전을 먼저 확인하도록 안내한다.
- 가격·할인율·배송일은 앱에 고정 표시하지 않고 쿠팡에서 최종 확인하게 한다.

## 개인정보와 기술

쿠팡 광고 스크립트와 iframe을 앱에 삽입하지 않는다. 제휴 페이지는 보호자노트 서버의 정적 설명과 외부 링크만 렌더링한다. 사용자가 링크를 직접 누르기 전에는 쿠팡에 환자·계정·돌봄방 정보가 전달되지 않는다. 내부 클릭 분석을 도입하더라도 카테고리와 배치 위치만 허용하고 민감 속성은 결합하지 않는다.

## 운영 점검

- 월 1회 링크 유효성, 상품 적합성, 고지 노출, 병원 안전 안내를 확인한다.
- 품절이나 과도한 가격 변동이 반복되면 해당 링크를 검색형 또는 다른 생활용품 링크로 교체한다.
- 쿠팡파트너스 정책이 바뀌면 고지와 링크 표시 방식을 즉시 갱신한다.
