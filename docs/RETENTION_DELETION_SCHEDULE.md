# 보유·삭제 일정

> 아래는 보수적 제품 기본값이다. 법적 근거와 사업자 정책은 출시 전 전문가가 확정한다.

| 정보 | 기본 보유 | 삭제/예외 |
|---|---|---|
| 계정 프로필/인증 연결 | 탈퇴 처리 완료까지 | 즉시 로그인 차단, 재가입 자동복원 금지 |
| 환자 케이스·문서·생활기록 | 케이스 종료/삭제 요청 후 30일 유예 | 철회 즉시 공유 중단; 원본·파생물 완전삭제 |
| 미사용 초대 | 만료/회수 후 30일 보안 증적 | 토큰 원문 미저장 |
| 마케팅 동의 이력 | 철회 후 분쟁·법적 증적에 필요한 기간 | 발송 대상에서는 즉시 제외 |
| 결제/계약/철회 기록 | 관련 법령상 기간(운영 전 확정) | 건강정보와 분리, 최소 필드·제한 접근 |
| 동의·정책 증적 | 처리 및 입증에 필요한 기간 | 본문 버전/해시 중심, 최소 기기정보 |
| 감사/보안 로그 | 기본 1년 | 사고/분쟁 hold 시 승인된 기간 연장 |
| 지원 문의 | 종결 후 기본 3년 | 사용자가 지원 접근 허용한 원문은 더 짧게 |
| 분석 이벤트 | 기본 13개월 | 가명 ID 삭제/회전, 민감 속성 금지 |
| 백업 | 순환 35일 | 삭제 데이터는 순환 만료, 복구 시 삭제목록 재적용 |

삭제 작업은 요청 접수→접근 차단→법적 hold/소유권/환불 확인→30일 격리→객체 원본과 썸네일/추출물 삭제→도메인 삭제/익명화→검증 증적 순이다. 보존 예외에는 근거, 범위, 승인자, 종료일을 기록한다. 암호화 키 폐기가 필요한 저장소에는 cryptographic erasure를 고려한다.
