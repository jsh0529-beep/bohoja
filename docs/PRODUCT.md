# 보호자노트 제품 정의

> 기준: `CODEX_PRODUCT_BUILD_BRIEF.md`. 이 문서는 제품 구현 기준이며 의료·법률 자문이 아니다.

## 목적과 사용자

보호자노트는 병원 안내문을 일정과 할 일로 정리하고 가족의 교대, 질문, 비용, 퇴원 준비를 함께 관리하는 한국어 우선 PWA다. 주 사용자는 입원한 부모·가족을 돌보는 성인 보호자, 원격 가족, 교대 보호자다.

제품은 진단, 검사 판독, 처방·복약 변경, 응급도 판단, 병원 공식 기록을 제공하지 않는다. 모든 의료 관련 화면에는 보호자 기록임과 병원 안내 재확인 필요성을 맥락에 맞게 알린다.

## 핵심 여정

1. 가입: 최소 계정정보, 만 14세 이상, 필수 동의를 분리하여 수집한다.
2. 케이스: 환자 별칭과 관계를 입력하고 민감정보 처리 및 적법한 권한을 별도 확인한다.
3. 안내문: 비공개 업로드 → fixture/AI 추출 → 원문 근거와 비교·수정 → 사용자 확인 후 일정·업무 생성.
4. 협업: 만료·회수 가능한 초대로 가족을 연결하고 OWNER/CO_ADMIN/CAREGIVER/VIEWER 권한을 적용한다.
5. 돌봄: 일정, 할 일, 생활기록, 질문, 교대 인계와 확인을 기록한다.
6. 퇴원: D-3/D-1/당일/72시간 항목, 담당자, PDF 패키지를 관리한다.
7. 상품: 무료 한도 후 테스트 결제로 입원 패스 또는 가족 케어 플랜을 활성화한다.
8. 권리: 동의 철회, 공유 회수, 내보내기, 정정·처리정지, 탈퇴·삭제를 제공한다.

## 상품 원칙

가격과 혜택은 관리자 데이터로 관리한다. 기본 제안은 무료(활성 케이스 1, 가족 5, 문서 3), 입원 패스(6,900원/60일, AI 30회), 가족 케어(월 4,900원 또는 연 39,000원)다. 결제하지 않아도 안전 고지와 자신의 데이터 접근·권리 행사는 제한하지 않는다. 제휴 카드는 `제휴`로 표시하고 제3자 제공 동의를 신청 시점에 별도로 받는다.

## 성공 지표

첫 케이스 생성, 첫 가족 연결, 업로드→추출 확인, 7일 내 교대 2회, 퇴원 체크리스트 완료, 유료 전환, 유효 제휴 리드를 본다. 환자명·질환·병원명·문서·메모 원문은 분석 속성으로 보내지 않는다.

## 출시 범위 밖

병원 EMR 연동, 의료진용 간호기록, 정밀 위치, 직접 간병 중개, 실제 PG/AI/알림 발송은 MVP 기본값이 아니다. 외부 계정이 없으면 교체 가능한 테스트 어댑터를 사용한다.
