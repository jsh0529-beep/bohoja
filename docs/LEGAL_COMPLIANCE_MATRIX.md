# 법적 준수 매트릭스

> 법률 자문이 아닌 개발 체크리스트. 출시 시점 최신 법령과 실제 사업 구조를 전문가가 검토해야 한다.

| 영역 | 제품 의무 | 구현/증적 | 담당 | 상태 |
|---|---|---|---|---|
| 개인정보 보호법 | 최소수집, 고지, 권리, 안전조치 | 가입/권리센터, 버전 동의, 감사로그 | 개인정보책임자 | 출시 전 검토 |
| 민감정보 | 건강정보 별도 동의와 접근제한 | CaseConsent, 케이스 RBAC, 비공개 저장 | 개인정보책임자 | 출시 전 검토 |
| 위탁/재위탁 | 수탁사·목적 공개 및 관리 | Processor CMS와 변경이력 | 개인정보책임자 | 공급자 확정 필요 |
| 국외 이전 | 국가·수령자·항목·시점·방법·기간·거부 영향 고지/근거 | 정책 버전, 케이스 AI 고지/동의 | 법무/개인정보 | 공급자 확정 필요 |
| 광고성 정보 | 채널별 수신 동의/철회, 발송 증적 | MarketingConsent, 발송 전 검사 | 마케팅 | 문구 검토 필요 |
| 전자상거래법 | 사업자·가격·기간·환불/청약철회 고지, 거래기록 | 결제 확인 화면, 정책 CMS, PaymentEvent | 커머스/법무 | 사업자·PG 확정 필요 |
| 전자금융/PG | 적법한 PG, 오류·분쟁 처리, 카드정보 미보관 | PaymentProvider, 서명 웹훅 | 재무/개발 | PG 계약 필요 |
| 의료/의료기기 | 진단·치료·복약 판단 금지 | AI 정책, 고지, 안전 테스트 | 제품/법무 | 기능 범위 검토 |
| 표시광고 | 의료효과·제휴 우월성 과장 금지 | 콘텐츠 승인, `제휴` 표시 | 마케팅/법무 | 출시 카피 검토 |
| 위치정보 | MVP 정밀 위치 미수집 | 스키마/권한에 위치 필드 없음 | 제품 | 기능 추가 시 재검토 |
| 만 14세 미만 | 초기 대상 제외, 연령 전체 미수집 | over14 확인과 가입 차단 | 제품/법무 | 문구 검토 |

운영 승인에는 확정 사업자정보, 개인정보처리방침/약관, 수탁사와 국외이전 현황, PG 환불 정책, 사고 연락망, 보존기간, 관리자 권한자 목록이 필요하다. 값이 없으면 실결제·실발송·운영 AI 전환을 차단한다.
